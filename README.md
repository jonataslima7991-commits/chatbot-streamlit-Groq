💡 Sobre o Projeto

Assistente de programação com IA que responde dúvidas sobre Python 
em linguagem natural — como ter um tutor pessoal disponível 24h.

Desenvolvido como parte do curso **Fundamentos de Linguagem Python** 
da Data Science Academy, com interface personalizada e integração 
com o modelo de linguagem via **Groq API**.


⚙️ Funcionalidades

- 💬 Respostas em linguagem natural sobre Python
- ⚡ Alta velocidade com Groq (Llama 3)
- 🎨 Interface temática inspirada no Homem de Ferro
- 🔑 Integração com sua própria API Key Groq

🛠️ Tecnologias

| Tecnologia | Uso |
|-----------|-----|
| Python | Linguagem base |
| Streamlit | Interface web |
| Groq API | Modelo de linguagem (Llama 3) |
| DSA Python | Curso base |

---

🚀 Como Rodar

```bash
# 1. Clone o repositório
git clone https://github.com/jonataslima7991-commits/chatbot-streamlit-Groq.git

# 2. Instale as dependências
pip install -r requirements.txt

# 3. Execute
streamlit run streamlit_app.py
```

> Você precisará de uma API Key gratuita do Groq:  
> https://console.groq.com
